Deployment: retain your existing environment variables on Render. For local use copy your original .env back (not included for security). Set EMAIL_NOTIFICATIONS_ENABLED=true, SMTP_FROM_EMAIL to a verified Brevo sender, ADMIN_NOTIFICATION_EMAIL to the intended admin inbox, PUBLIC_FRONTEND_URL to your actual frontend. Recommended: set BREVO_API_KEY to a Brevo transactional API key (not SMTP password); this selects HTTPS instead of SMTP. Without it, complete Admin Settings SMTP takes precedence over environment SMTP. Keep SETTINGS_ENCRYPTION_KEY unchanged. Node 18+ required for HTTPS fetch. Check logs for [notification-mail] accepted or errors. Provider acceptance is not inbox delivery; check Brevo transactional logs. To retry previously failed jobs, after reviewing delivery history and avoiding uncertain deliveries, in MongoDB update selected failed records to state pending, attempts 0, nextAt current date, error empty. No automatic resend of exhausted jobs to avoid duplicates. Existing dashboard notifications are unchanged. API-mode inline images use data URIs which some mail clients may suppress.
